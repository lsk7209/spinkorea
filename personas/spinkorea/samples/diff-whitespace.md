# 문서 비교에서 공백 차이만 따로 읽는 법

문서 비교 화면이 온통 변경 표시로 보일 때 실제 내용보다 줄바꿈이나 끝 공백이 원인인 경우가 있습니다. 원본과 수정본의 출처를 고정하고, 먼저 문단 단위 변경을 찾은 다음 공백 차이를 별도로 살펴보세요.

회의록 초안을 비교한다면 제목과 결정 사항처럼 의미가 바뀐 줄을 먼저 검토합니다. 서식 정리 과정에서 생긴 빈 줄은 두 번째 단계로 미루면 중요한 수정이 묻히지 않습니다. 다만 코드나 Markdown에서는 공백도 문법이 될 수 있으므로 무조건 무시하면 안 됩니다.

`/tools/diff-checker`에는 공개되어도 되는 예시만 붙여 넣습니다. 고객 정보나 API 키가 있는 문서는 로컬 편집기의 비교 기능을 사용하고, 최종 문서 길이까지 확인하려면 `/tools/text-counter`로 이어갑니다.
