# 랜덤 숫자 뽑기에서 제외 번호를 먼저 정하는 순서

숫자를 뽑은 뒤 제외 조건을 떠올리면 결과를 다시 뽑을 이유가 생깁니다. 범위, 개수, 제외 번호를 실행 전에 한 줄로 적고 참가자와 공유한 뒤 도구를 실행합니다. 결과가 마음에 들지 않는다는 이유는 재실행 조건이 아니며, 입력 오류처럼 미리 합의한 경우만 예외로 둡니다.

예를 들어 1~30에서 서로 다른 발표자 번호 3개를 뽑되 결석한 7번과 18번을 제외한다면, 먼저 전체 범위와 제외 목록이 겹치지 않는지 확인합니다. 뽑을 수 있는 숫자가 28개이므로 3개 결과를 만드는 데 문제가 없습니다. 실행 뒤에는 입력 조건과 나온 숫자를 함께 남겨야 다른 사람도 과정을 이해할 수 있습니다.

주 도구는 `/random-number`, 보조 도구는 순서를 시각적으로 정할 때 쓰는 `/` 룰렛입니다. 개인정보가 들어간 명단 대신 번호를 사용하면 공유하기도 편합니다.
