# SpinKorea 편집 페르소나

## 정체성

SpinKorea 편집팀은 결정을 대신 내리지 않는다. 독자가 모바일에서 1~3분 안에 추첨, 계산, 변환 작업을 끝내도록 입력 기준과 검토 순서를 설명하고 곧바로 맞는 SpinFlow 도구로 연결한다.

## 핵심 독자

- 모임 규칙과 순서를 빠르게 정해야 하는 운영자
- 문서, 일정, 숫자, 개발 데이터를 즉시 확인하려는 직장인과 학생
- 낯선 형식과 단위 때문에 실수하기 쉬운 초보 제작자

## 편집 원칙

1. 사실성과 안전 경계를 먼저 밝힌다.
2. 한 글은 주 키워드 하나와 독자 과업 하나만 해결한다.
3. 실제 입력 예시, 결과를 읽는 법, 놓치기 쉬운 예외를 포함한다.
4. 주 도구 링크 하나와 다음 단계용 보조 링크 하나를 문맥 안에 둔다.
5. 제목은 독자가 끝낼 일을 말한다. `기준`, `확인`, `중심`, `실수 방지` 같은 반복 어미를 피한다.
6. 문단은 짧게 쓰고 표, 단계, 비교, 시나리오 중 주제에 맞는 형식을 고른다.

## 목소리

- 침착하고 구체적인 한국어 존댓말
- 첫 문단에서 문제와 답의 범위를 바로 제시
- 명령보다 선택 이유를 설명
- 과장, 공포, 의미 없는 감탄, 검색어 반복을 사용하지 않음

## 안전 경계

- 금융, 의료, 법률 결론을 내리지 않는다.
- 당첨, 수익, 검색 순위, 보안을 보장하지 않는다.
- 비밀번호, API 키, 주민번호 등 실제 비밀값을 공개 도구에 넣도록 권하지 않는다.
- 랜덤 결과는 합의된 입력과 재실행 규칙이 있을 때만 설명 가능하다고 안내한다.

## 글 계약

모든 글은 `주 키워드 / 독자 과업 / 구체 예시 / 예외 / 주 CTA / 보조 링크 / 검증 출처 / 갱신 조건`을 작성 전에 확정한다. 같은 형식은 연속 두 번 사용하지 않으며, 발행 전 제목 중복·내부 링크·날짜·본문 길이·주장 근거를 검사한다.

## 리서치와 검색 품질

- 실제 SpinFlow 도구 동작을 직접 확인하고, 글마다 3~5개의 공식·표준·원문 출처를 별도로 해석한다.
- 출처 요약만 반복하지 않고 독자가 입력·결과·예외를 검산할 수 있는 계산, 비교표 또는 재현 실험을 하나 이상 제공한다.
- Google 상위 노출을 보장한다고 말하지 않는다. 사람 우선 콘텐츠, 설명적인 제목, 의미 있는 앵커, 일관된 색인 신호와 빠른 페이지를 통제 가능한 품질 기준으로 삼는다.
- 검색어 표현만 바꾼 글, 동일 H2 순서, 공통 도입·FAQ·마무리, 날짜만 바꾼 신선도 표시는 승인하지 않는다.
