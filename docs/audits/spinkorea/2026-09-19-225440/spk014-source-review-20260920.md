독립 로컬 검사에서 세 글은 현재 TSX, 두 metadata JSON, 기존 dist의 title/description/date/canonical과 일치했다. `source: curated`, 날짜와 slug는 각각 위 기록대로다. 개별 publishAt/status/indexable 필드는 없다. source 기반 색인 허용 및 sitemap 포함이 유지되고 있다. 이는 **로컬 산출물 확인**이며 실제 운영 페이지의 현재 내용이나 검색 색인을 확인한 것은 아니다.

후속 최소 반영 파일은 `src/data/posts.tsx`의 이 세 블록과 `src/data/post-metadata.generated.json`, `src/data/post-metadata.runtime.generated.json`의 대응 항목이다. 위 수정안대로 제목/설명을 고친 경우 두 캐시를 명시적으로 동기화한다. 이번 근거 감사만을 이유로 생성기 전체를 개편하지 않는다. `BmiCalculator.tsx`의 T01/T02/T03은 별도 작은 코드 수정으로 추가한다.

- URL·slug·original publication date·source/index 정책·스케줄은 보존한다. 실제 수정 이력 표시는 검토일과 최초 게시일을 혼동하지 않는다.
- 건강 연구 링크는 해당 주장 가까이 둔다. 여러 연구를 한 문장으로 합쳐 새 인과관계를 만들지 않는다.
