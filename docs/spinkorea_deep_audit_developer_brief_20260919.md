# spinkorea.kr 심층 재검토 · 개발자 실행 명세
검토일: 2026-09-19 (Asia/Seoul)
대상: spinkorea.kr / SpinFlow
성격: 공개 자료에 근거한 읽기 전용 감사. 운영 사이트 수정·배포·삭제는 수행하지 않음.

## 1. 범위와 증거 해석

- /tools의 도구 링크 51개, /blog의 글 링크 86개를 목록 기준으로 확인했다. 전체 URL 수 또는 Google 색인 수라는 의미는 아니다.
- 대표 페이지의 공개 본문, 검색 요약, Google 공식 문서, 기술·보건 원자료를 비교했다.
- 실제 도구 입력·버튼·모바일 화면의 브라우저 종단 테스트는 미수행이다.
- 서버 코드, 원본 HTTP 응답 헤더, robots/sitemap/ads.txt 내용, canonical/noindex 전체, 서버 로그, GSC, GA4, AdSense 계정·거절 메시지는 미확인이다.
- 일부 URL의 조사 도구 접근 실패는 사이트 장애 또는 404로 확정하지 않는다.
- 수집 본문에서 보이지 않는 요소가 실제 렌더링 화면에도 없다고 단정하지 않는다.
- 기존 보고서의 67/100 및 Crawl PASS는 이번 감사에서 확정 결과로 유지하지 않는다.

근거 분류:
[ADSENSE-OFFICIAL]은 Google 광고 정책·운영 문서,
[SEARCH-QUALITY]는 검색 품질·색인 문서,
[EXPERT-INFERENCE]는 발견 사항의 해석 및 개선 제안이다.

Evidence의 Confirmed는 명시한 관찰 사실이 확인되었다는 뜻이다. 거절 원인 확정, 기능 검증 완료, AI 작성 판정을 뜻하지 않는다.

## 4. 개발자가 확인해야 할 위치와 작업 계약

저장소를 보지 않았으므로 아래는 실제 파일명이 아니라 찾아야 할 역할이다.
공통 금지: 프레임워크 전환, 전면 디자인 변경, 정상 계산식 임의 변경, 운영자 정보·검수 경력·테스트 성과 날조, 승인용 글 대량 생성, 모든 오래된 URL 일괄 삭제.

### A01 — 공개 URL 단일 인벤토리
위치: 콘텐츠 저장소, 발행 상태 필드, 라우트 생성부, 빌드 산출물, sitemap/RSS 생성부, 캐시 설정.
원하는 동작:
- 저장소/빌드/허브/sitemap에서 확보한 URL의 합집합을 만든다.
- URL별 title, content type, publish state, 허브 연결, HTTP 상태, canonical, robots, sitemap 포함 여부, 광고 노출 여부, 조치 상태를 기록한다.
- random-choice-log가 목록 밖에서 계속 접근되는 이유를 확인한다. 목록 제외와 게시 중단을 혼동하지 않는다.
수정 금지: 목록에서 빠졌다는 이유만으로 삭제, 동일 검색 의도가 아닌 페이지로 일괄 리디렉션.
완료 기준: 모든 확인 URL에 담당 조치와 공개 상태가 지정되고 서로 다른 목록의 차이가 설명된다.
테스트: 내부 링크 크롤링과 빌드·콘텐츠 원본 대조. GSC 자료가 있으면 실제 유입·색인 자료를 별도 열로 추가한다.

### A02 — 수면 글 리빌드
위치: 해당 글 원본, 수면 계산기 설명·결과 문구, 관련 링크.
원하는 동작: 산식을 검산하고 가정에 따른 시간 계산과 실제 수면 단계 판정을 분리한다.
- 90×4+30분 = 390분 = 6.5시간이다.
- 반감기 6시간을 가정한 단순 모델에서 10시간 후 잔존 비율은 약 31.5%다. 개인의 실제 대사량이라는 뜻이 아니다.
- 90분 간격이라는 가정만으로 특정 기상 시각이 잘못됐다고 판정하지 않는다.
완료 기준: 수치 재계산 일치, 보건 원자료의 범위 명시, 건강 효과 보장 제거, 도구 설명과 글의 가정 일치.
수정 금지: 개인별 수면 처방을 새로 작성하거나 다른 근거 없는 숫자로 교체.

### A03 — 비밀번호 글 리빌드
위치: 보안 관련 글 원본 및 비밀번호 생성기 구현.
원하는 동작: 공격 환경이 빠진 해독 기간을 삭제하거나 검증 가능한 가정과 함께 제한적으로 설명한다. MFA를 만능 보장으로 표현하지 않는다.
- 알려진 예시 문자열을 실제 사용하도록 유도하지 않는다.
- 기술 검토는 난수 생성, 선택 편향, 로그·전송·저장 여부를 포함한다.
- NIST 문서는 인증 시스템 기준을 설명하는 참고자료다. 생성기에 적용되는 AdSense 필수 규정으로 표현하지 않는다.
완료 기준: 무조건적 보안 보장 0건, 출처·범위 연결, 구현 검증 결과와 안내 일치.
테스트: 실제 비밀번호가 아닌 더미 자료와 개발 환경으로만 수행. 실제 계정 침입·크래킹 시험 금지.

### A04 — 랜덤 결과 기록 글 재작성
위치: 해당 글 원본, 관련 템플릿·생성 데이터.
원하는 동작: 조사 오류 교정에서 끝내지 않고 실제로 사용할 기록 양식으로 대체한다.
제안 양식: 실행 시각 / 참가자 목록 버전 / 제외 조건 / 중복 당첨 허용 / 재추첨 규칙 / 실행 결과 / 변경 이력.
주의: MDN의 getRandomValues 설명은 난수 API의 참고 근거다. 운영 효율·기록 절차 전체의 효과를 입증하는 출처처럼 사용하지 않는다.
완료 기준: 설명만 읽어도 하나의 예시 기록을 완성할 수 있고, 모호한 변수 치환 문장이 남지 않는다.
예시는 가상이라고 표시하며 실제 사용자 사례를 만들지 않는다.

### A05 — 본문과 렌더링의 의미 일치
위치: HTML 생성부, 클라이언트 UI, 콘텐츠 데이터, head/metadata, 프리렌더 및 CDN 캐시.
원하는 동작: 원본 HTML, 깨끗한 브라우저의 렌더링 DOM, 검색 수집 결과가 중요한 설명에서 충돌하지 않는다.
- 글자수, 문의, 개인정보 페이지를 우선 비교한다.
- 검색 요약은 과거 버전 또는 재구성 결과일 수 있어 실시간 본문과 완전히 같을 필요는 없다.
- JavaScript 사용 자체를 결함으로 취급하지 않는다.
완료 기준: 제목·정의·계산 규칙·개인정보·문의 경로의 누락/충돌 원인이 확인되고 수정 후 재검증된다.
테스트: 저장소·쿠키 없는 세션, JS 활성/비활성 비교, 가능 시 GSC 실시간 URL 검사. 동일 문자를 요구하지 않고 의미·필수 정보의 일치를 검사한다.
수정 금지: 검색 봇에만 키워드·설명·기능을 다르게 제공하는 우회 구현.

### A06 — 개인정보와 입력값 데이터 흐름
위치: 개인정보 문서, 분석 이벤트, 에러 로깅, 공유 URL, 브라우저 저장소, 외부 SDK·API, 광고·CMP 설정.
원하는 동작: 실제 처리와 안내 문구가 일치한다. 계산 입력과 광고·분석용 방문 정보 처리를 구분한다.
검증: 더미 문자열이 분석 이벤트, 요청 URL, 에러 보고, 공유 링크, 외부 QR 요청에 포함되는지 네트워크와 저장소에서 확인.
완료 기준: 미고지·불필요한 민감 입력 전송 0건, Google 광고 쿠키 고지 항목 대조 완료.
조건부: EEA/UK/스위스 이용자에게 개인맞춤 광고를 제공한다면 Google 인증 CMP 요건을 확인한다. 방문 국가·광고 설정은 현재 미확인이다.
수정 금지: 검증 없이 “모든 데이터가 절대 전송되지 않음”이라고 선언.

### A07 — 크롤러·공개 상태
위치: robots, sitemap, 메타 robots, X-Robots-Tag, canonical, 리디렉션, WAF, 로그.
원하는 동작: 공개·검색·광고 노출 정책이 일관되게 적용된다.
검증 대상: Googlebot, Mediapartners-Google, Google-Display-Ads-Bot. User-Agent 모의 요청만으로 실제 Google 접근을 입증했다고 판단하지 않는다.
완료 기준: 대표 URL의 정상 응답·본문, 실제 접근 제한 원인, sitemap URL의 공개 상태가 확인된다.
주의:
- noindex는 검색 결과 제어이며 AdSense 정책 적용에서 페이지를 제외하는 스위치가 아니다.
- robots 차단으로 noindex를 읽을 수 없게 만들지 않는다.
- ads.txt 상태는 계정 정보와 대조한다. 다른 사이트의 게시자 ID를 복사하지 않는다.
- 삭제·리디렉션은 URL별 내용과 유입 정보를 검토한 뒤 별도 승인 범위에서 수행한다.

### A08 — 기능·모바일·광고 회귀 테스트
위치: 도구 UI/로직, 클립보드·다운로드, 결과 영역, 광고 슬롯 및 자동 광고 설정.
원하는 동작: 정상·경계·오류 입력을 예측 가능한 결과로 처리한다.
완료 기준: 아래 테스트 통과 및 도구 설명과 결과 일치. 작은 화면에서 핵심 입력·결과·버튼이 가려지지 않는다.
광고: 조작 영역·복사·다운로드와 혼동되지 않게 분리. 오류/빈 시스템 화면의 광고 요청 여부 점검.
안전: 실제 광고 클릭·반복 광고 노출 테스트 금지. 광고를 모의 처리하거나 테스트 환경을 사용한다.

### A09 — 콘텐츠 통합과 보존
위치: CSS/Yes-No 게시글, 내부 링크, 리디렉션 설정.
원하는 동작:
- CSS 기본 설명 두 글은 합칠 가치와 고유 부분을 비교한다.
- 상태·포커스 접근성 글은 별도 목적이 있으므로 보존한다.
- Yes/No의 위험 결정 권장 범위를 사이트 전반에서 일관되게 정리한다.
완료 기준: 선택한 대표 URL의 독립적 가치 유지, 통합 대상 링크 정리, 필요 시 동등한 내용으로 1단계 리디렉션.
수정 금지: 글이 오래됐다는 이유만으로 통합, 유입 자료 없이 기존 성과 URL을 무조건 새 URL로 변경.

### A10 — 관련 도구 연결
위치: 도구 메타데이터와 추천 렌더링.
원하는 동작: text-counter는 단어 빈도·문서 비교·텍스트 변환 등 같은 작업과 연결한다.
완료 기준: 대표 페이지마다 관련 링크의 연결 이유를 설명할 수 있다. 전역 인기 도구는 별도 라벨로 구분한다.
테스트: 자기 자신·중복·없는 URL 제외, 추천 클릭 경로 확인.
수정 금지: 실제 코드를 보기 전에 배열 slice 오류라고 원인 확정.

### A11 — 문의·FAQ
위치: 문의 페이지와 실제 수신 경로, FAQ 데이터·렌더링.
원하는 동작: 사용자가 실제로 문의할 수 있는 수단을 표시하고 기능·저장·공유·오류에 관한 직접 답변을 제공한다.
완료 기준: 운영자가 합의한 수신 경로에서 테스트 수신 및 오류 안내 확인. 불필요한 개인정보 수집 없이 이용 가능.
주의: 본 감사는 메일이나 문의 폼을 전송하지 않았다. 실제 전송 테스트는 운영자가 승인한 환경에서 한다.

### A12 — 사용자 중심 허브
위치: /tools, /blog 및 공통 설명 템플릿.
원하는 동작: 기능 목록·검색·작업 분류를 우선하고 심사 목적 설명을 제거한다.
완료 기준: “AdSense 검토자”를 향한 문장 제거, 반복 설명 축소, 필요한 정책 문서·광고 고지는 보존.
수정 금지: AdSense 단어 전역 삭제, 개인정보 문서의 필수 광고 고지 삭제.

## 6. 콘텐츠 자체의 고유 가치 제안

신규 기능은 제안이며 이미 구현된 것으로 간주하지 않는다.
- 랜덤: 후보·제외·중복 허용·재추첨 기준을 함께 담은 결과 기록.
- 글자수: UTF-8/코드포인트/UTF-16/제출처 별도 기준을 구분한 해설과 실제 계산 예제.
- 날짜: 경과일과 양 끝 날짜 포함 일수의 명시적 구분.
- 계산: 결과뿐 아니라 공식·입력 전제·반올림·기준일 표시.
- 보안·개인정보: 실제 네트워크 검증에 근거한 처리 범위 설명.

비교한 공개 서비스:
Wheel of Names FAQ는 난수 방식·반복 결과·당첨자 제외를 설명한다.
timeanddate는 종료일 포함 옵션을 명시한다.
계산기닷컴은 글자수·바이트 계산 규칙을 설명한다.
이 서비스들의 승인 상태·검색 순위·모든 수치 정확성은 검증하지 않았다. 내용을 그대로 복제하지 않는다.

## 7. 작업 순서와 검토 문턱

1~2일차 제안: URL 인벤토리, 수면·보안 사실 오류 및 반복 글 처리안.
3~4일차 제안: 렌더링 비교, 개인정보·문의 실사용 검증, 크롤러 접근 확인.
5~6일차 제안: 대표 도구 회귀 테스트, 콘텐츠 통합과 관련 링크 정리.
7일차 제안: 변경 URL 재크롤링 및 세 Gate 재검증.
이는 운영자가 선택할 작업 일정이지 자동 실행 예약 또는 완료 약속이 아니다.

재신청 검토 Gate:
- Policy: 실제 개인정보 고지·광고 배치·필요한 동의 요건 검증 전 판정 보류.
- Crawl & Function: 원본 응답·실제 봇 접근·도구 테스트 전 미검증.
- Publisher Value: 확인된 사실 오류와 반복형 글 개선 필요.
확인되지 않은 사항을 0점 또는 만점 처리하지 않는다. 전체 100점 점수는 필수 검증 이후 산정한다.
